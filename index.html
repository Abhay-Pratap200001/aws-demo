S3 DEPLOYMENT

How This Website Works

This website uses Amazon S3 to host static HTML and CSS files.

1

Create S3 Bucket

Create an S3 bucket with a unique bucket name in your AWS account.

2

Upload Files

Upload index.html and style.css into the S3 bucket.

3

Configure Website

Enable static website hosting and configure the index document.

4

Access Website

Use the S3 website endpoint to access the deployed static website.
